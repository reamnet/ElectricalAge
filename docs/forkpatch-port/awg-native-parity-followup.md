# Native versus AWG adapter audit

Implementation after this audit is recorded in [native AWG implementation results](awg-native-implementation-results.md).
The conversion, terminal and repeated-tap entries below describe the audit baseline, not the implemented milestone status.

Audit base: `2c6b81655`, after original develop and AWG reliability integration. This supersedes the older starting-state tables in `awg-native-parity.md`; those tables describe stages of development, not current architecture.

The reference is native cable functionality. AWG is a descriptor-specific electrical/material backend of the native placement path, not a second routing engine. No Qwen geometry branch was integrated or edited during this audit.

## Paired regression and evidence

`AwgNativeLengthCase` uses the same descriptor-sized native router on identical full-block supports at two elevations, with three native waypoints and a 65 m centerline. Before the fix native placement passed and AWG refused only the legacy limit. The fix changes no search, geometry, descriptor, registry ID or saved field.

The regression checks native success, AWG success, exact 65 m debit from 65.125 m, rollback after 35 attempted parts with unchanged world/spool/simulator counts, and exact 65 m removal refunds. Existing paired slab, wall/outer-corner, span, tap and shared-session fixtures remain the reference for supported shapes. After the fix, all assertions pass. Focused units: 39/39, exit 0. Focused server: 67/67 including the new case and all existing AWG cases, exit 0. The progress document records commands and outcomes, including the before-fix failure. The wider full suite was not rerun for this one-condition adapter change; its latest baseline remains 2,091/2,094 with the three historical failures. No unrun scenario is claimed verified.

## Recommended order for further parity work

1. Add paired powered native/AWG fixtures for offset device pins and same-block repeated taps before extending terminal-joint metadata.
2. Extend shared native piece provenance to separate paid centerline from visual stubs/extensions, then adapt AWG edges and both-end corner ownership. Reuse native geometry output and Mimic transactions.
3. Generalize shared cached-route validation with paired stale support/obstruction tests; retain exact funding and generation checks.
4. Retire redundant legacy placement controls only after their supported saves/operations and native replacements are explicitly covered.

All 70 identities, resistance/rating/thermal definitions, save compatibility and existing electrical ownership rules are protected. This audit identifies remaining parity gaps; it does not claim they are all solved or that live placement has been visually inspected.
